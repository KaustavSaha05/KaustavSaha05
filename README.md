## 🚀 Projects

### 🏥 Medi-AI-Agent: Multi-Agent Medication Management

An intelligent multi-agent system for personalized medication management. Three cooperating agents (Medication Manager, Nurse, Monitor) handle drug interaction detection, adherence trend monitoring, and empathetic patient coaching, grounded in clinical guidelines through a FAISS-based RAG pipeline with Gemini 2.5 Flash and a Streamlit dashboard. This work was presented at IEM ICDC 2026.

### 🐞 BugX: AI-Powered Code Review Platform

A full-stack code review web app with an in-browser code editor and AI-powered defect detection, security audits, and optimization suggestions via Gemini. It includes user authentication (Argon2id hashing, cookie sessions) and a PostgreSQL persistence layer with Drizzle ORM.
